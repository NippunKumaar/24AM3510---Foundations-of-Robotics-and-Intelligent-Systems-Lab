# Foundations of Robotics and Intelligent Systems - Lab Materials

This repository contains the Python/Jupyter lab materials for 24AM3510.

## First-time setup

1. Create and activate a workspace-local Python virtual environment.
2. Install the packages listed in requirements.txt.
3. Select the virtual environment as both the VS Code Python interpreter and the Jupyter notebook kernel.

Do not commit the .venv folder. It is excluded by .gitignore; each user creates it locally from requirements.txt.
